Safety boundary: investigation side cannot execute external effects
State pattern: file artifacts + thread memory + version hashes
Cost control: tool budget denylist + per-agent cost ledger ceiling
High-level intent: let agents do reasoning and trade-off synthesis, but let deterministic code own truth, authorization, and irreversible actions.
